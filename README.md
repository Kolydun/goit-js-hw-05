# goit-js-hw-05

Домашнє завдання. Тема 8. Перебираючі методи масивів.

## Структура

- `js/task-1.js` — Задача 1. Імена користувачів (`getUserNames`, `map`)
- `js/task-2.js` — Задача 2. Користувачі з другом (`getUsersWithFriend`, `filter`)
- `js/task-3.js` — Задача 3. Сортування за кількістю друзів (`sortByDescendingFriendCount`, `toSorted`)
- `js/task-4.js` — Задача 4. Загальний баланс (`getTotalBalanceByGender`, `filter` + `reduce`)

Результати виконання виводяться в консоль розробника.
